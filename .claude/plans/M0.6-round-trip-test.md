## Goal (from PLAN.md M0.6)

One pytest that drives the **live** round-trip `agent → mock → agent` over **real HTTP
sockets** and asserts:
1. the returned payload matches the `wiki/evals/address/expected.json` `gov-id-clean`
   entry (id + key fields), i.e. the eval data survived the full A2A envelope; and
2. `TASK_STATE_WORKING` was **observed before** `TASK_STATE_COMPLETED` (the async
   `message/send` → poll `tasks/get` → `COMPLETED` path was actually exercised, not a
   blocking sleep).

The ~10s hold must be shrinkable for the test.

This is the M0 **validation gate**: it proves `CollectRequest` in / `ExchangeTurn`
out round-trips cleanly through canonical A2A on a live socket, with a real ADK
`LlmAgent` driving the turn.

## Design decisions (make these; they are the non-obvious calls)

### 1. How to run a live server — background thread (recommended)
Run the mock in a **daemon thread** with its own event loop, and drive the client from
the main thread via `asyncio.run`. This cleanly separates the server loop from the
client loop and avoids uvicorn signal-handler issues:
`uvicorn.Server.run()` internally does `asyncio.run(self.serve())`, and
`install_signal_handlers()` is a no-op off the main thread — so a daemon thread is
safe. Readiness = poll `server.started`. Shutdown = set `server.should_exit = True`,
then `thread.join(timeout=5)`.

> Alternative (same-loop): create `server.serve()` as an `asyncio.create_task` inside
> the client's loop, `await` until `server.started`, then `server.should_exit=True`.
> Also works, but shares one loop and runs signal-handler install on the main thread.
> Prefer the thread approach.

### 2. Free port + card-url invariant
Pick a free port **before** creating the app (the app bakes `base_url` into the card):
```python
import socket
def _free_port() -> int:
    s = socket.socket()
    s.bind(("127.0.0.1", 0))
    port = s.getsockname()[1]
    s.close()
    return port
```
Then `base_url = f"http://127.0.0.1:{port}"`, `create_app(base_url, hold_seconds=...)`,
`uvicorn.Config(app, host="127.0.0.1", port=port, log_level="warning")`. (Tiny TOCTOU
race window is acceptable for a local test.)

### 3. Hold + poll tuning (non-flaky, still exercises the poll path)
Use `hold_seconds=1.0` on the mock and `poll_interval=0.05` on the client. This
guarantees the send returns `WORKING` **and** several `tasks/get` polls also observe
`WORKING` before `COMPLETED` (~1s / 0.05s ≈ many polls), so the async surface is
genuinely exercised — not just inferred from the send response. Keep the client's
`poll_timeout` at its default (30s) or set 10s. Total added runtime ≈ ~1s.
- Note: the ordering assertion (`WORKING` before `COMPLETED`) holds even at
  `hold_seconds=0` (send always returns WORKING first), but a ~1s hold is what lets the
  stronger "a *poll* saw WORKING" assertion be non-flaky. Don't shrink below ~0.5s.

### 4. Capturing the payload — drive the runner directly (recommended)
`run_once()` returns only the scripted final text, not the tool result, so it can't be
used to assert the payload. Drive the `InMemoryRunner` **inside the test** and capture
the tool's `function_response` from the event stream (this keeps it to ONE live
round-trip and stays faithful to "a real `LlmAgent` drove the turn"):
```python
from google.adk.runners import InMemoryRunner
from google.genai import types
from agents.address.agent import APP_NAME, PARTY

runner = InMemoryRunner(agent, app_name=APP_NAME)
await runner.session_service.create_session(app_name=APP_NAME, user_id=PARTY, session_id="m0-6")
captured = []
final_text = ""
async for event in runner.run_async(
    user_id=PARTY, session_id="m0-6",
    new_message=types.Content(role="user", parts=[types.Part(text="Collect the address proof.")]),
):
    if event.content and event.content.parts:
        for part in event.content.parts:
            if getattr(part, "function_response", None) is not None:
                captured.append(part.function_response.response)  # == collection_to_dict(turn)
            elif part.text:
                final_text = part.text
payload = captured[0]
```
> Simpler fallback if event-capture is fiddly: call the tool closure directly —
> `payload = await agent.tools[0].func()` — which runs the real client round-trip and
> returns `collection_to_dict`. This is still "the agent's own Bridge call over the
> live socket." If you use the fallback, additionally call `run_once(agent)` and assert
> `final_text == "Collected the address proof."` so a real `LlmAgent` turn is still
> exercised. (The recommended approach covers both in one turn.)

Assert on `client.observed_states` **after** the turn (it reflects the last `collect`).

### 5. Payload assertion — read `expected.json` independently (avoid tautology)
The mock loads its answer from the same eval file, so comparing against
`load_gov_id_clean_entry()` would be nearly circular. Read `expected.json` **raw** in
the test and assert the payload's key fields against it, proving the data survived the
A2A wire:
```python
import json
from pathlib import Path
evals = json.loads((Path(__file__).resolve().parents[2] / "wiki/evals/address/expected.json").read_text())
gov = next(d for d in evals["documents"] if d["id"] == "gov-id-clean")
expected_key_fields = gov["extraction"]["fields"]["key_fields"]
```
(`parents[2]` from `agents/tests/test_round_trip.py` → repo root `/home/boris/working`.)

### 6. Async test entry
Wrap the client-side coroutine in `asyncio.run(...)` from a **sync** test function
(matches `test_bridge_client.test_collect_errors_offline`). Do **not** use
`@pytest.mark.anyio` here — uvicorn needs an asyncio loop and `asyncio.run` guarantees
one without depending on the anyio backend selection.

## Assertions (the acceptance checks inside the test)

Payload (§5):
- `payload["documents"]` has length 1.
- `doc = payload["documents"][0]`; `doc["id"] == "gov-id-clean"`;
  `doc["doctype"] == "gov-id"`; `doc["disposition"] == "accepted"`.
- `doc["key_fields"] == expected_key_fields` (full dict equality against raw
  `expected.json`), which includes `name == "Jordan Lee"` and
  `address == "14 Elm Row, Springfield"`.
- `payload["context_id"]` is a non-empty `str` (server-assigned A2A context id,
  backfilled by the client — do not hardcode a value).

Async path (§3, via `observed = client.observed_states`):
- `TaskState.TASK_STATE_WORKING in observed`.
- `TaskState.TASK_STATE_COMPLETED in observed`.
- `observed.index(TaskState.TASK_STATE_WORKING) < observed.index(TaskState.TASK_STATE_COMPLETED)`.
- `observed[-1] == TaskState.TASK_STATE_COMPLETED`.
- (Recommended, non-flaky at hold=1.0/interval=0.05) `observed.count(
  TaskState.TASK_STATE_WORKING) >= 2` — proves a `tasks/get` poll (not just the send)
  saw `WORKING`. If this ever flakes on a slow box, raise `hold_seconds` before
  weakening the assertion.

If using the fallback in §4, also: `final_text == "Collected the address proof."`.

## Gotchas recap
- `base_url` given to `create_app` MUST match the uvicorn host:port (card-url invariant).
- Close the `A2ABridgeClient` (`async with`) — it owns its httpx client.
- Read `observed_states` **after** the turn; it resets each `collect()`.
- Don't assert payload against `load_gov_id_clean_entry()` (tautology) — read
  `expected.json` raw.
- Use `asyncio.run` (not `@pytest.mark.anyio`) so uvicorn gets an asyncio loop.
- Don't sleep in the executor path — it's already correct; only tune `hold_seconds`
  from the app factory.
