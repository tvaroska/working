# S0.2 — `bridge/` core project scaffold (separate uv project + isolation guard)

**Sprint:** 0 (scaffolding) · **Task line:** `PLAN.md` S0.2
**Depends on:** S0.1 (CI already wired for a `core` job) · **Feeds:** S0.3 (seam harness), S0.7 (dev-env `setup` target), S0.8 (contract-sharing sign-off)
**Related ADRs:** `docs/decisions/adr-0001-stack.md` (pins, native-first), `adr-0009`/`adr-0010` (consumer side — not touched here). New ADR authored here: `adr-0011` (contract sharing — **Proposed**, ratified at S0.8).

## Goal (scope of THIS task only)

Stand up the **reusable Bridge core** as a **separate uv project rooted at `bridge/`**, mirroring the existing `agents/` project's toolchain exactly, plus the **isolation guard test** that locks the invariant `bridge/` never imports `agents/` in CI. Record the contract-type-sharing decision as an ADR (Proposed).

This ships **no domain behavior** — no Collect logic, no canonicalization/disposition, no `is_satisfied`, no real Bridge, no GCP adapters (those are Sprint 1/2). `bridge/src/bridge/` is a placeholder package with a docstring only.

**Explicitly NOT in this task:**
- Do **not** physically move `contract` out of `agents/src/`. That move is gated on the S0.8 sign-off of the contract-sharing ADR (PLAN S0.2 step 2: "Record the choice in an ADR **before** moving `contract` out"). This task only *authors the ADR (Proposed)* and scaffolds `bridge/`; the extraction is a later task once sign-off lands.
- Do not add any real Bridge module, seam interface, or adapter. S0.3 establishes the seam harness; Sprint 1 designs the seam interfaces.
- Do not edit `.github/workflows/ci.yml` — the `core` job already exists and is correctly guarded (`hashFiles('bridge/pyproject.toml') != ''` gates it on; it runs `uv sync --locked` → `uv run ruff check .` → `uv run pytest`, and its comment already references `tests/test_no_agents_import.py`). Once this task lands `bridge/pyproject.toml` + `bridge/uv.lock`, that job activates automatically.

## Context an executor needs (do not re-derive)

- **The repo is multi-project.** `agents/` is its own uv project (root `agents/pyproject.toml`, own `.venv`, own `uv.lock`). `bridge/` is a **peer** project with the same structure — NOT a workspace member, NOT sharing `agents/`'s lockfile. Run all `uv`/`pytest`/`ruff` commands from inside `bridge/`.
- **`agents/` is the template to mirror.** Read `agents/pyproject.toml` (reproduced below) and `agents/tests/test_scaffold.py` before writing anything. Match style, naming, and structure.
- **The invariant** (CLAUDE.md): `bridge/` never imports `agents/`; parity between them holds *by discipline* + the shared seam suite, not by import. Because `bridge/` is a physically separate uv project, `agents` is not even installed in `bridge/`'s venv — so `import agents` fails there anyway. The guard test is still required: it locks the invariant in CI and catches a future accidental dependency add.
- **Contract-sharing is an OPEN decision** (PLAN S0.2 step 2, S0.8 gate). Recommended target = a **shared third `contract` package** both `agents/` and `bridge/` depend on (neither imports the other; a shared third package is allowed and preserves the invariant). Alternative = duplicate-by-discipline. This task records the recommendation in `adr-0011` as **Proposed** and defers the physical restructure.
- **Package manager is uv** (v0.9.x installed). Interpreter: CPython 3.12.3. Commit `uv.lock` (it is NOT gitignored — SDK pins are load-bearing per ADR-0001). `.gitignore` already covers `.venv/`, `.ruff_cache/`, `.pytest_cache/`, `*.egg-info/`.

## Ordered steps

1. **`bridge/.python-version`** — single line: `3.12` (mirror `agents/.python-version`; keeps uv from resolving/building against a newer Python than we run).

2. **`bridge/pyproject.toml`** — hand-write (do NOT use `uv init`'s flat default; we need the src layout). Same pins as `agents/`:
   - `[project]`: `name = "a2a-document-bridge-core"`, `version = "0.0.0"`, `requires-python = ">=3.12"`,
     `dependencies = ["google-adk>=2.7.0,<3", "a2a-sdk[http-server]", "pydantic>=2"]`. (Same pins per PLAN S0.2.1; the core will host the real Bridge `LlmAgent` + a2a server + Pydantic domain logic, so all three are load-bearing.)
   - `[dependency-groups]`: `dev = ["pytest>=8", "ruff>=0.6"]`.
   - `[build-system]`: `requires = ["hatchling"]`, `build-backend = "hatchling.build"`.
   - `[tool.hatch.build.targets.wheel]`: `packages = ["src/bridge"]` (single package under `src/` — mandatory so hatchling locates it for the editable install).
   - `[tool.ruff]`: `line-length = 100`, `target-version = "py312"`, `src = ["src", "tests"]`.
   - `[tool.ruff.lint]`: `select = ["E", "F", "I"]`.
   - `[tool.pytest.ini_options]`: `testpaths = ["tests"]`, `addopts = "-ra"`.

3. **Package skeleton:**
   - `bridge/src/bridge/__init__.py` — docstring only, naming its future role, e.g.
     `"""A2A Document Bridge core — the reusable mediation layer (Sprint 1+ fills this)."""`
     Keep it import-clean: it must NOT import anything from `agents` (the whole point) and, to keep the guard robust, should not import heavy SDKs at module load either (a bare placeholder).

4. **`bridge/tests/__init__.py`** — empty.

5. **`bridge/tests/test_no_agents_import.py`** — the isolation guard (PLAN S0.2.3). It must:
   - `import bridge` (the top-level core package).
   - Scan `sys.modules` and assert **no** key is the `agents` top-level package or a submodule of it.
   - **GOTCHA — match the package, not the substring.** `google.adk.agents` contains the substring `agents` but is NOT our `agents` package. The check must be: a module name `m` is a violation iff `m == "agents" or m.startswith("agents.")`. Do **not** use `"agents" in m` or `m.startswith("agents")` (the latter would also flag a hypothetical `agentsomething`).
   - Assert with a message listing any offending module names for a clear CI failure.

   Skeleton:
   ```python
   """Isolation guard: `bridge` must never import the `agents` package (CLAUDE.md invariant)."""

   import sys


   def test_bridge_does_not_import_agents():
       import bridge  # noqa: F401

       offenders = [m for m in sys.modules if m == "agents" or m.startswith("agents.")]
       assert not offenders, f"bridge pulled in agents modules: {sorted(offenders)}"
   ```

6. **(Optional but recommended) `bridge/tests/test_scaffold.py`** — mirror `agents/tests/test_scaffold.py` as a pin-guard for the core project so SDK-pin drift is caught in the `core` CI job too (ADR-0001 SDK risk; the CI `core` job runs the whole suite, not a named test). Same three assertions: importable SDKs (`a2a`, `google.adk`, `pydantic`) + local `import bridge`; `google-adk` major==2 and (major,minor)>=(2,7); `a2a-sdk` version non-empty. Keep it if it costs little; the isolation guard is the mandatory one.

7. **`docs/decisions/adr-0011-contract-type-sharing.md`** — record the contract-sharing decision (PLAN S0.2.2). Follow the house ADR format (see `adr-0009`): front-matter block (**Status: Proposed**, Date, Scope, Context links), then Context / Decision / Rationale / Consequences / Alternatives. Content to capture:
   - **Decision (recommended):** a **shared third package `contract`** that both `agents/` and `bridge/` depend on (as a uv path dependency), so neither imports the other and the `bridge/ never imports agents/` invariant is preserved (a shared *third* package is explicitly allowed by CLAUDE.md). Import name stays `contract` in both projects (no call-site churn when it moves).
   - **Alternative considered:** duplicate-by-discipline (each project keeps its own copy, kept in parity by the shared seam suite). Rejected as the target because it invites drift on the load-bearing wire types, but noted as the fallback.
   - **Status = Proposed; ratified at S0.8.** The physical move of `contract` out of `agents/src/` happens in a follow-up task *after* sign-off — NOT in S0.2. Note the mechanics for that follow-up: new `contract/` project (or `packages/contract/`) with its own `pyproject.toml`; both `agents/pyproject.toml` and `bridge/pyproject.toml` add a `[tool.uv.sources]` path dependency; drop `src/contract` from `agents/`'s wheel-packages list; re-lock both; `test_scaffold.py`'s `import contract` keeps working.
   - Cross-reference: PLAN S0.2 / S0.8, CLAUDE.md "Core vs. demos" + the invariant.

8. **Materialize env & lock** (from within `bridge/`): run `uv sync`. This creates `bridge/.venv`, `bridge/uv.lock`, installs `bridge` editable. **Commit `bridge/uv.lock`.**

9. **Verify** (all from within `bridge/`):
   - `uv run pytest` → green (isolation guard + optional scaffold test pass).
   - `uv run ruff check .` → clean (fix any lint in the files you wrote — import order etc.).
   - `uv run python -c "import bridge; print('ok')"` → prints `ok`.
