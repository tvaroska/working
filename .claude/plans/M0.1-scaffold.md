# M0.1 — Scaffold (uv project, `agents/` package, pinned SDKs, pytest + ruff)

**Milestone:** 0 — Contract Tracer Bullet · **Task line:** `PLAN.md` M0.1
**Full milestone spec:** `docs/milestone-0-contract-tracer.md` (task 1) · **Stack ADR:** `docs/decisions/adr-0001-stack.md`

## Goal (scope of THIS task only)

Stand up the **minimal Python toolchain + package skeleton** that tasks M0.2–M0.7 slot into. Nothing more:
create the `agents/` uv project with a `src/` layout containing the (empty) `contract` and `agents` packages, pin
the load-bearing SDKs, wire pytest + ruff, and prove the install resolves & imports with one smoke test.

**Explicitly NOT in this task** (they are M0.2+): contract Pydantic models, the `BridgeClient` port, the mock
Bridge server, the address `LlmAgent`, the round-trip test, the run doc (`agents/README.md`). Do **not** implement
those — only create the directory skeleton they will live in. This is the "minimal slice of Sprint-0 scaffolding —
only what M0 needs" per PLAN.md.

## Context an executor needs (do not re-derive)

- This is a **docs-first repo** — there is currently **no** application code, no `pyproject.toml`, no `.venv`. You
  are creating the first executable slice. (`CLAUDE.md` "Repository status".)
- The whole backend/agents project is **rooted at `agents/`** (not repo root). The milestone doc fixes these paths:
  `agents/src/contract/`, `agents/src/agents/mock_bridge/`, `agents/src/agents/address/`, `agents/README.md`. So
  `pyproject.toml` lives at `agents/pyproject.toml` with a **src layout**, and there are **two** importable top-level
  packages under `agents/src/`: `contract` and `agents`. Import names are `contract` and `agents` (e.g.
  `from agents.mock_bridge import ...`, `import contract`).
- `bridge/` (the reusable core) is a **separate** project that does not exist yet and is **out of scope** here. Do
  not create it. Invariant: `bridge/` never imports `agents/` — irrelevant to M0.1 but don't blur the boundary.
- Package manager is **uv** (installed, v0.9.1). Interpreter present: CPython **3.12.3**. Run tests with
  `uv run pytest`; lint with `uv run ruff check`. (`CLAUDE.md` "Intended stack & commands".)
- `.gitignore` already covers `.venv/`, `.ruff_cache/`, `.pytest_cache/`, `*.egg-info/`. It does **not** ignore
  `uv.lock` — that is intentional; **commit `uv.lock`**.

## Verified facts (probed during planning — trust these)

- The pin set **resolves cleanly** on this machine: `uv lock` with
  `google-adk>=2.7.0,<3`, `a2a-sdk`, `pydantic>=2` → **google-adk 2.7.0, a2a-sdk 1.1.2, pydantic 2.13.4**
  (68 pkgs, ~0.6s). `google-adk` transitively pulls `fastapi` and `uvicorn`, so those need no explicit pin for M0.
- **GOTCHA (most important):** `a2a-sdk`'s core distribution is **client-only** (it pulls `httpx` for the
  `BridgeClient` in M0.3). The **server** side (Starlette + `sse-starlette`) that the **mock Bridge in M0.4** needs
  lives behind an **extra**. Declared extras include `http-server`, `fastapi`, `all`. Pin **`a2a-sdk[http-server]`**
  now so M0.4 doesn't have to touch dependencies. (`fastapi` extra also works but is heavier; `http-server` is the
  minimal Starlette server surface.)
- `uv lock` without a pinned interpreter grabbed CPython 3.14. Pin the dev interpreter to 3.12 via a
  `.python-version` file so the venv uses the installed 3.12.3 and we don't resolve against a Python we don't run.
- Import names for the smoke test: distributions are `google-adk` / `a2a-sdk`; use
  `importlib.metadata.version("google-adk")` and `version("a2a-sdk")` rather than a module `__version__` attribute
  (not guaranteed to exist).

## Ordered steps

1. **`agents/.python-version`** — single line: `3.12`.

2. **`agents/pyproject.toml`** — hand-write (do NOT rely on `uv init`'s default flat layout; we need the two-package
   src layout). Content:
   - `[project]`: `name = "a2a-document-bridge-agents"`, `version = "0.0.0"`, `requires-python = ">=3.12"`,
     `dependencies = ["google-adk>=2.7.0,<3", "a2a-sdk[http-server]", "pydantic>=2"]`.
   - `[dependency-groups]` (uv dev group): `dev = ["pytest>=8", "ruff>=0.6"]`.
   - `[build-system]`: `requires = ["hatchling"]`, `build-backend = "hatchling.build"`.
   - `[tool.hatch.build.targets.wheel]`: `packages = ["src/agents", "src/contract"]`  ← required, else hatchling
     cannot locate two packages under `src/` and the editable install fails.
   - `[tool.ruff]`: `line-length = 100`, `target-version = "py312"`, `src = ["src", "tests"]`.
     `[tool.ruff.lint]`: `select = ["E", "F", "I"]` (pycodestyle, pyflakes, isort). Keep modest.
   - `[tool.pytest.ini_options]`: `testpaths = ["tests"]`, `addopts = "-ra"`. (No `pythonpath` needed — the project
     is installed editable via hatchling, so `agents`/`contract` import directly.)

3. **Package skeletons** (create the dirs + `__init__.py` files the later tasks fill in):
   - `agents/src/contract/__init__.py` — empty (docstring only).
   - `agents/src/agents/__init__.py` — empty (docstring only).
   - `agents/src/agents/mock_bridge/__init__.py` — empty placeholder (M0.4 fills it).
   - `agents/src/agents/address/__init__.py` — empty placeholder (M0.5 fills it).
   Each `__init__.py` should carry a one-line module docstring naming its future role so the dirs aren't bare.

4. **`agents/tests/__init__.py`** — empty. **`agents/tests/test_scaffold.py`** — the M0.1 acceptance test. It must:
   - Import `google.adk`, `a2a`, `pydantic`, and the local packages `contract` and `agents` — proving pins are
     installed and the src layout is importable.
   - Assert `google-adk` version is in range: parse `importlib.metadata.version("google-adk")`, assert major == 2
     and (major, minor) >= (2, 7).
   - Assert `importlib.metadata.version("a2a-sdk")` is a non-empty string (loose — no upper pin on a2a-sdk).

5. **Materialize the environment & lock:** run `uv sync` (from `agents/`). This creates `agents/.venv`,
   `agents/uv.lock`, and installs the project editable. **Commit `uv.lock`.**

6. **Verify** (all from within `agents/`):
   - `uv run pytest` → green (the one scaffold test passes).
   - `uv run ruff check` → clean (fix any lint in the files you just wrote).
   - `uv run python -c "import agents, contract; from importlib.metadata import version; print(version('google-adk'), version('a2a-sdk'))"`
     → prints `2.7.0 1.1.2` (or resolved equivalents), proving both packages import and SDKs are present.

## Gotchas recap

- Pin **`a2a-sdk[http-server]`**, not bare `a2a-sdk` — the server extra is needed by M0.4 and bare a2a-sdk is
  client-only. Adding it now avoids a dependency churn commit mid-milestone.
- The wheel-target `packages = ["src/agents", "src/contract"]` line is mandatory for two src packages under one
  hatchling project; omitting it breaks the editable install (packages won't be found).
- Commit `uv.lock` (not gitignored) — SDK versions are load-bearing per ADR-0001 and must be reproducible.
- Pin dev interpreter with `.python-version = 3.12` so uv doesn't resolve/build against a newer Python than the one
  the project runs on.
- Run all `uv`/`pytest`/`ruff` commands from inside `agents/` (or pass `--project agents`); the project root is
  `agents/`, not the repo root.
