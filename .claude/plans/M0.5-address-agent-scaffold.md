## Goal (scope of THIS task only)

Build a **real ADK `LlmAgent`** at `agents/src/agents/address/` that performs the agent half of the tracer-bullet round-trip:

1. Wires the injected `BridgeClient` port as an ADK **tool** (a `FunctionTool` closing over the client).
2. On one turn, requests **`address-proof` for party `jordan-lee`** (both values hard-coded per M0 — no skills registry), awaits the result through the port (`collect` → `ExchangeTurn`), and **renders the returned `id` + structured info**.
3. Is a genuine `google-adk` `LlmAgent` (day-one platform bet — ADR-0001), constructed via a factory that takes the `BridgeClient` so M0.6 can inject a client pointed at a live mock with a shrunk hold.

This is the agent half of the contract validation. **No** Collect loop, `is_satisfied` gate, disposition, real extraction, chase/HITL, frontend, GCP, persistence, or skills registry — all Sprint 1+.

**Explicitly NOT in this task:**
- No live end-to-end socket round-trip (uvicorn mock + real `A2ABridgeClient`) — that is **M0.6**. M0.5's tests are network-free: they inject a fake in-memory `BridgeClient` (and, for the full-agent-run test, a scripted stub LLM), no sockets, no Gemini API key.
- No real Gemini call in tests. The production model string is configurable but tests use a scripted `BaseLlm` stub so CI is hermetic.
- No changes to `contract`, `bridge_client`, or `agents.mock_bridge`.

## Critical context an executor MUST NOT re-derive

### Installed versions & verified API surface
- `google-adk == 2.7.0`, `a2a-sdk` 1.1.x (protobuf-typed — same gotchas as M0.3/M0.4, but M0.5 barely touches raw A2A; it goes through the port).
- `from google.adk.agents import LlmAgent`. Relevant fields (verified): `name`, `description`, `model` (accepts a **`str` model id OR a `BaseLlm` instance**), `instruction`, `tools`, `output_key`.
- `from google.adk.tools import FunctionTool`; `FunctionTool(func)` wraps a callable. **Async functions are supported** (pass a coroutine function). ADK builds the function declaration from the signature + docstring, so give the tool a clear docstring and typed return.
- `from google.adk.runners import InMemoryRunner`. `InMemoryRunner(agent, app_name=...)`. Drive a turn with `runner.run_async(user_id=..., session_id=..., new_message=types.Content(...))` → async generator of `Event`. You must create a session first via `runner.session_service.create_session(app_name=..., user_id=..., session_id=...)` (await it).
- `from google.adk.models import BaseLlm, LlmResponse`. `BaseLlm` is a pydantic model with one field `model` and one abstract method:
  `async def generate_content_async(self, llm_request: LlmRequest, stream: bool = False) -> AsyncGenerator[LlmResponse, None]`.
- `from google.genai import types`. **Verified constructors** for the stub model:
  - Function call: `types.Content(role="model", parts=[types.Part(function_call=types.FunctionCall(name="collect_address_proof", args={}))])`
  - Final text: `types.Content(role="model", parts=[types.Part(text="...")])`
  - Wrap either in `LlmResponse(content=<content>)`.

### The standard ADK function-calling loop (how one turn actually runs)
When the agent runs a turn, ADK calls the model, and:
1. Model emits a `function_call` part → ADK executes the matching tool → appends the tool's `function_response` to the conversation → **calls the model again**.
2. Model then emits a final `text` part → turn ends.

So the **scripted stub model** only needs an internal call counter (no need to parse the request): **call #1 → emit the `collect_address_proof` function_call; call #2+ → emit a final text part** (echo the rendered summary or a fixed "done" string). This makes the *real* `LlmAgent` + `Runner` run the true tool→port path deterministically with no API key. This is the key decision that keeps M0.6 hermetic while honoring the "real ADK `LlmAgent`" platform bet.

### Wiring the `BridgeClient` as a tool — the seam
- The agent depends only on the **`BridgeClient` port** (M0.3). The factory injects a concrete client; the tool closes over it. This is why the Sprint-1 mock→real swap is a no-op for the agent: only the injected client changes.
- The tool is a **no-arg** async closure (party + skill are hard-coded for M0): it builds `CollectRequest(party="jordan-lee", skill="address-proof")`, calls `await bridge_client.collect(request)`, and returns a JSON-serializable dict of the `id` + structured fields (ADK tool results must be dict-like). Catch `BridgeClientError` and return an error dict (`{"error": str(exc)}`) so the model/turn can still complete — do NOT let a transport error crash the run.
- Do the rendering in a **pure deterministic function** `render_collection(turn) -> str`, not in the LLM's free text — M0.6 asserts against the tool result / render output, never against LLM prose (there is no real LLM in tests).

### Import discipline
- `agents.address` MAY import: `contract`, `bridge_client`, `google.adk`, `google.genai`, stdlib.
- `agents.address` MUST NOT import `agents.mock_bridge` — the agent does not know the mock exists; M0.6 wires agent↔mock together. (Parity between agent and mock holds by discipline through the shared wire encoding, not shared code — per CLAUDE.md.)
- No `pyproject.toml` edit needed — `src/agents` is already a wheel package.

### Seams touched
This is the **`BridgeClient` port**, consumer side (the agent core / thin driver that consumes the port). There is **no new seam and no GCP adapter** in M0.5 — the port already exists (M0.3) with its single A2A adapter; M0.5 only *consumes* it. Keep the factory injection clean so Sprint 1 can swap the concrete client with zero agent changes.

## Gotchas checklist (do not trip on these)

- **LlmAgent needs a model to route** — a real Gemini call would break CI. Inject the scripted `BaseLlm` stub in tests; only `__main__` uses the real model string.
- The scripted stub keys off a **call counter** (call #1 → function_call, later → final text), matching ADK's function-calling loop (model → tool → model again). Don't try to parse the `LlmRequest`.
- `BaseLlm` is a **pydantic** model — hold the mutable call counter with `PrivateAttr` (or reset per instance), not a bare class attribute.
- **Tool results must be JSON-serializable dicts** — return `collection_to_dict(turn)`, not the raw pydantic `ExchangeTurn`.
- The tool is **no-arg** (party/skill hard-coded) — keep the signature clean with a docstring so ADK's auto function-declaration is valid for the real model.
- Catch `BridgeClientError` inside the tool and return an error dict — don't let a transport failure crash the whole run.
- Assert on the **tool result / `render_collection` output**, never on free-form LLM text (there's no real LLM in tests; the stub's final text is fixed).
- Drive async tests with `asyncio.run` (repo has **no pytest-asyncio**; `@pytest.mark.anyio` is used only for the in-process ASGI test in `test_mock_bridge.py`). Follow the `test_bridge_client.py::test_collect_errors_offline` pattern.
- `InMemoryRunner.run_async` requires a pre-created session (`await runner.session_service.create_session(...)`); forgetting it raises a session-not-found error.
- Do NOT import `agents.mock_bridge` from `agents.address` (only from test code). Do NOT edit `pyproject.toml` (`src/agents` already packaged).
- Rendering is the deterministic contract surface — keep `render_collection` output stable across runs (no timestamps, dict order rides insertion order per the models).
