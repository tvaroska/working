— strip only `Ltd/Inc/LLC/GmbH/…` ("co" is **not** a suffix); handle camelCase suffix
fragmentation (test the joined last-two tokens) (lessons A4). **Build fresh in `bridge/`** (cannot
import `agents/`); keep in parity with `wiki/evals/address/expected.json` (`issuer_raw`→`issuer`)
via the shared suite. *(Standalone; used by M1.6.)*

## Algorithm (specify exactly — this is the load-bearing detail)

Function: `canonicalize_issuer(raw: str | None) -> str | None`

1. **Null/empty passthrough.** If `raw is None` or `raw.strip() == ""`, return `None`. (Parity:
   `issuer_raw: null` → `issuer: null`. Do **not** return `""`.)
2. **Split camelCase into tokens**, applied to the whole trimmed string, using two regex passes so
   both "word→Word" and "ACRONYM→Word" boundaries break, and importantly so a *joined* suffix like
   `GmbH` fragments (this is what A4 wants you to then re-join):
   - `re.sub(r"(?<=[a-z0-9])(?=[A-Z])", " ", s)` — insert a space between a lower/digit and an
     uppercase (`PowerCo` → `Power Co`, `AquaUtil` → `Aqua Util`, `...GmbH` → `...Gmb H`).
   - `re.sub(r"(?<=[A-Z])(?=[A-Z][a-z])", " ", s)` — insert a space inside an acronym run before a
     capitalized word (defensive; harmless on the fixtures).
3. **Tokenize** on any run of non-alphanumeric characters: `re.split(r"[^A-Za-z0-9]+", s)` and drop
   empty tokens. (`"Power Co."` → `["Power", "Co"]`; the trailing `.` is dropped.)
4. **Strip trailing corporate-suffix tokens** using a **set of lowercased suffixes**. Check, from the
   tail, in this order and repeat while a match is found:
   - the **joined last-two tokens** lowercased (handles the `Gmb`+`H` → `gmbh` fragmentation) — if it
     matches, drop **both** tokens;
   - else the **single last token** lowercased — if it matches, drop it;
   - else stop.
   `SUFFIXES = {"ltd", "limited", "inc", "incorporated", "llc", "gmbh", "plc", "corp",
   "corporation", "llp", "lp", "ag", "sa", "nv", "bv", "pty"}`. **`"co"` and `"company"` are NOT in
   the set** (A4: "co" is not a suffix — this is the whole point of the task).
5. **Guard against over-stripping:** if stripping would remove *all* tokens (input was purely a
   suffix, e.g. `"Ltd"`), do **not** strip — fall back to the pre-strip token list. (Decision:
   safer to keep something than emit `None`/empty for a real string. Not exercised by fixtures;
   document it.)
6. **Lowercase remaining tokens and join with `-`:** `"-".join(t.lower() for t in tokens)`.
   (`["Power","Co"]` → `"power-co"`, `["Aqua","Util"]` → `"aqua-util"`, `["Gov"]` → `"gov"`.)

Trace checks (put these in the tests):
- `"PowerCo"` → split `Power Co` → tokens `[Power, Co]` → no suffix (`co` not in set) → `power-co` ✓
- `"Power Co."` → tokens `[Power, Co]` → `power-co` ✓
- `"PowerCo Ltd"` → tokens `[Power, Co, Ltd]` → last `ltd` ∈ set → drop → `[Power, Co]` → `power-co` ✓
- `"AquaUtil"` → `[Aqua, Util]` → `aqua-util` ✓
- `"Gov"` → `[Gov]` → `gov` ✓
- `"Foo GmbH"` → split `Foo Gmb H` → `[Foo, Gmb, H]` → joined last-two `gmbh` ∈ set → drop both →
  `[Foo]` → `foo` ✓
- `None` → `None`; `"   "` → `None`

**Idempotence:** `canonicalize_issuer(canonicalize_issuer(x)) == canonicalize_issuer(x)` must hold
(already-canonical `power-co` re-canonicalizes to `power-co`: `[power, co]`, `co` not stripped).
Add a test for this — it is the property that lets `satisfaction.py` trust the ledger is canonical.
