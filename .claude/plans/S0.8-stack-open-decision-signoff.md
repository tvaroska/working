# S0.8 — Stack + open-decision sign-off (gate, not code)

**Sprint:** 0 (scaffolding) · **Task line:** `PLAN.md` S0.8
**Goal:** Resolve and **record** the decisions Sprint 1 builds on, so they are *designed in, not
retrofitted*. This is a **sign-off gate** — it ships **no application code, no seams, no domain
behavior, no `contract/` move**. Deliverables are documentation artifacts (ADR edits, one new ADR,
PLAN notes) plus a reproducibility re-check. When this lands, the Sprint-0 validation gate is
satisfiable: contract-sharing strategy, seam list, and the experimental-surface register are
"agreed and pinned."
