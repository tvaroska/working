## Goal (scope of THIS task only)

Build an `a2a-sdk` **server** at `agents/src/agents/mock_bridge/` that:
1. Serves a minimal **Agent Card** at `/.well-known/agent-card.json` advertising a JSON-RPC interface and one `address-proof` skill.
2. On `message/send`, creates an in-memory task, emits **`WORKING`** immediately (so `send_message` with `return_immediately`/polling returns `Task{WORKING}`), **holds ~10s (configurable)**, then attaches an artifact and marks the task **`COMPLETED`**.
3. The completion artifact is a single JSON DataPart carrying a full **`ExchangeTurn`** whose `CollectionStatus.ledger` has **one `LedgerEntry`** (the `gov-id-clean` document) loaded from `wiki/evals/address/expected.json`.

This is the mock half of the tracer-bullet round-trip. It exists to validate the input/output design (`CollectRequest` in → `ExchangeTurn{CollectionStatus{LedgerEntry}}` out over the canonical long-running poll surface). **No** Collect loop, disposition logic, real extraction, chase, HITL, GCP, or persistence (in-memory task store only). Only `gov-id-clean` is returned; the multi-doc ledger is Sprint 1.

**Explicitly NOT in this task:**
- No ADK agent / tool wiring — that is M0.5.
- No live end-to-end round-trip test spinning uvicorn against `A2ABridgeClient` — that is M0.6. M0.4's tests are network-free (fixture loader, executor event sequence, card/app assembly, optional in-process ASGI card fetch).
- No streaming, `tasks/resubscribe`, push notifications, cancel semantics beyond the SDK default.

## Critical context an executor MUST NOT re-derive

### The installed `a2a-sdk` is **1.1.2 — fully protobuf-typed**. Design docs predate it.
Same gotcha M0.3 documented. A2A types (`Message`, `Task`, `Part`, `AgentCard`, `AgentInterface`, `AgentCapabilities`, `AgentSkill`, `TaskState`, `Role`) are **protobuf messages** from `a2a.types`. Build with kwargs, read with `.field` / `.HasField(...)`. **Never `.model_dump()`** on them. `TransportProtocol` is **not** in `a2a.types` — import from `a2a.utils.constants` (`from a2a.utils.constants import TransportProtocol`); it is a `str, Enum` with `TransportProtocol.JSONRPC.value == "JSONRPC"`.

### The wire encoding is FIXED by M0.3 — the server MUST emit it bit-for-bit.
(from `.claude/plans/M0.3-bridge-client-port.md` and `agents/src/bridge_client/a2a_client.py`)
- **Inbound the client sends:** the `CollectRequest` as a single JSON DataPart in the `message/send` `Message`. The mock does **not** need to parse it for M0 (it always answers with `gov-id-clean`), but it MUST read `context.context_id` to stamp the outbound `ExchangeTurn.context_id`.
- **Outbound the mock MUST emit:** on `TASK_STATE_COMPLETED`, the full **`ExchangeTurn`** (not a bare `CollectionStatus`) as a **single JSON DataPart inside `task.artifacts[0]`**. The client does `ExchangeTurn.model_validate(get_data_parts(task.artifacts[0].parts)[0])`. Build the part with `new_data_part(turn.model_dump(mode="json"))` from `a2a.helpers.proto_helpers` (`mode="json"` so optionals/enums are JSON-native). This is the exact inverse of `task_to_exchange_turn` in `a2a_client.py`.
- The client backfills an empty `context_id` from `task.context_id`, so stamping the turn's `context_id` is belt-and-suspenders — do it anyway (set it from `context.context_id`).

### Server assembly (verified against the installed 1.1.2 API)
There is **no** `A2AStarletteApplication`/apps module in this version. Assemble a Starlette app from route builders:
- **Executor:** subclass `AgentExecutor` (`from a2a.server.agent_execution import AgentExecutor`), implement `async def execute(self, context, event_queue)` and `async def cancel(self, context, event_queue)`.
  - Inside `execute`, use `TaskUpdater` (`from a2a.server.tasks import TaskUpdater`): `updater = TaskUpdater(event_queue, context.task_id, context.context_id)`.
  - Sequence: `await updater.start_work()` → `await asyncio.sleep(self._hold_seconds)` → `await updater.add_artifact([new_data_part(turn.model_dump(mode="json"))])` → `await updater.complete()`.
  - **Why `start_work()` first:** the default handler's `on_message_send` (verified in `default_request_handler_v2.py`) subscribes with `replace_status_update_with_task=True` and, when `return_immediately` is set (the client passes `polling=True`), **breaks and returns the Task built from the first enqueued status event.** So `start_work()` makes `message/send` return `Task{WORKING}` immediately while `execute()` continues in a background task. The 10s sleep keeps the stored task in `WORKING`, so `tasks/get` polls observe `WORKING` before `COMPLETED` — exactly what M0.6 asserts. Do NOT sleep before `start_work()` (that would delay the send response by 10s and defeat the async surface).
  - The framework creates the task before `execute` runs; `context.task_id` / `context.context_id` are populated. `cancel()` can just `await updater.cancel()` (M0 has no real cancel path; keep it minimal).
  - **Terminal-state rule (gotcha):** `TaskUpdater` raises `RuntimeError` if you emit a status after a terminal state. Emit `WORKING` (non-terminal) → artifact (not a status) → `complete()` exactly once. Do not call `start_work()` twice.
- **Handler:** `from a2a.server.request_handlers import DefaultRequestHandler` (this is `DefaultRequestHandlerV2`). Construct `DefaultRequestHandler(agent_executor=<executor>, task_store=InMemoryTaskStore(), agent_card=<card>)`. `InMemoryTaskStore` from `a2a.server.tasks`.
- **Routes:** `from a2a.server.routes import create_jsonrpc_routes, create_agent_card_routes`.
  - `create_agent_card_routes(agent_card)` → serves the card at `/.well-known/agent-card.json` (default `card_url`).
  - `create_jsonrpc_routes(handler, rpc_url="/")` → JSON-RPC endpoint at `/` (matches `DEFAULT_RPC_URL` and the card interface URL below).
  - Build the app: `from starlette.applications import Starlette; app = Starlette(routes=[*create_agent_card_routes(card), *create_jsonrpc_routes(handler, rpc_url="/")])`.
  - **Graceful shutdown (recommended):** wire `handler.aclose()` into a Starlette shutdown handler / lifespan so the background `execute()` task drains on server stop. Not strictly required for M0.6 (which shrinks the hold), but cheap and correct — include it.

### The Agent Card the client can actually select (critical — get this exact)
The client (`A2ABridgeClient.collect`) does `A2ACardResolver(...).get_agent_card()` then `ClientFactory(ClientConfig(streaming=False, polling=True)).create(card)`. `ClientFactory.create` (verified) iterates `card.supported_interfaces` and picks the one whose `protocol_binding` is in the client set (default `[TransportProtocol.JSONRPC]`), then uses that interface's `url` as the RPC endpoint. So the card MUST include:
- `supported_interfaces=[AgentInterface(url=f"{base_url}/", protocol_binding=TransportProtocol.JSONRPC.value, protocol_version="1.0")]` — `protocol_binding` is the **string** `"JSONRPC"`; `url` MUST be the externally reachable RPC URL **including the trailing `/`** (matches `rpc_url="/"`). `base_url` = e.g. `http://127.0.0.1:8080`.
- `capabilities=AgentCapabilities(streaming=False, push_notifications=False)` — client uses `streaming=False`, so no streaming needed. (`on_message_send_stream` is guarded by `capabilities.streaming`; leaving it False is correct for M0.)
- `name`, `description`, `version="0.0.0"` (or similar).
- `default_input_modes=["application/json"]`, `default_output_modes=["application/json"]`.
- `skills=[AgentSkill(id="address-proof", name="Address proof collection", description="...", tags=["address"], input_modes=["application/json"], output_modes=["application/json"])]`.

**Because the card's interface `url` must match the bound host:port, the card is built from a `base_url` param** — `create_app(base_url, ...)` bakes it in. The `__main__` entrypoint derives `base_url` from the host/port it binds (see below).

### Package placement & import discipline
- Code lives under `agents/src/agents/mock_bridge/`. `src/agents` is already in `pyproject.toml` wheel packages — **no pyproject edit needed** (unlike M0.3).
- `mock_bridge` MAY import `contract` (domain models), `a2a-sdk`, `starlette`, stdlib. Honors the repo rule that server and client sides agree on the wire *by discipline*, not by shared code.

### Seams touched
This is the **A2A edge** (agent↔Bridge transport), server side. In the repo's local/GCP framing the mock is a **transport/target double**, not an InMemory-vs-GCS backend pair — so there is **no GCP adapter** to write here (the InMemory task store is the SDK's; a real Bridge is Sprint 1 behind the same A2A edge). Keep the mock self-contained so Sprint 1 grows it into the multi-turn contract double without agent changes.

## Gotchas checklist (do not trip on these)

- A2A types are **protobuf**, not pydantic — no `.model_dump()` on `Task`/`Message`/`AgentCard`; build with kwargs, read with `.field`/`.HasField`.
- `TransportProtocol` is in `a2a.utils.constants`, **not** `a2a.types`; `protocol_binding` on `AgentInterface` is the **string** `"JSONRPC"` (use `TransportProtocol.JSONRPC.value`).
- The card's interface `url` MUST be the reachable RPC URL **with trailing `/`** and match `rpc_url="/"`; a mismatch means the client can't find the endpoint.
- `start_work()` FIRST, then sleep — sleeping before the first status event would delay the `message/send` response by ~10s and break the async poll surface the milestone exists to prove.
- `TaskUpdater` forbids status updates after a terminal state — emit WORKING once, then artifact, then `complete()` once; never `start_work()` twice.
- Use `new_data_part(turn.model_dump(mode="json"))` (`mode="json"`) — `ParseDict` into `google.protobuf.Value` needs JSON-native values.
- Wrap the whole `ExchangeTurn` in the artifact (not a bare `CollectionStatus`) — the client validates `ExchangeTurn`.
- Load the eval fixture once at app construction, not per request.
- Set `capabilities.streaming=False` — the client uses `streaming=False, polling=True`; streaming isn't needed and enabling it isn't required.
- Wire `handler.aclose()` into Starlette `on_shutdown` so the background `execute()` task drains cleanly.
- Do NOT edit `pyproject.toml` — `src/agents` is already a wheel package.
