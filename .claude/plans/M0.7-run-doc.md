
**Mock server** — entrypoint `agents/src/agents/mock_bridge/__main__.py`:
- Command: `uv run python -m agents.mock_bridge`
- Env vars (all optional, with defaults):
  - `MOCK_BRIDGE_HOST` (default `127.0.0.1`)
  - `MOCK_BRIDGE_PORT` (default `8080`)
  - `MOCK_BRIDGE_HOLD_SECONDS` (default `10.0`) — how long it holds in `WORKING` before `COMPLETED`.
- On start it prints the base URL, the Agent Card URL (`/.well-known/agent-card.json`), the
  JSON-RPC URL (`/`), and the hold duration.
- Returns a single accepted `gov-id-clean` document sourced from
  `wiki/evals/address/expected.json`.

**Address agent (manual driver)** — entrypoint `agents/src/agents/address/__main__.py`:
- Command: `uv run python -m agents.address`
- This runs a **real ADK `LlmAgent` with a real model**, so it needs model credentials
  (`GOOGLE_API_KEY`, or Vertex AI env config). The model id defaults to `gemini-2.0-flash`
  and is overridable via `ADDRESS_AGENT_MODEL` (see `agents/src/agents/address/agent.py`).
- Env var `BRIDGE_BASE_URL` (default `http://127.0.0.1:8080`) points it at the running mock.
- Requires the mock to already be running (separate terminal). For a quick manual run, start the
  mock with a short hold, e.g. `MOCK_BRIDGE_HOLD_SECONDS=2 uv run python -m agents.mock_bridge`,
  so you are not waiting the full 10s.
- Prints the rendered document id + structured fields.

**Test** — `agents/tests/test_round_trip.py` (plus the rest of the suite):
- Command: `uv run pytest` (single test: `uv run pytest tests/test_round_trip.py`).
- **The test suite is fully hermetic**: it spins up its own mock on a free port in a daemon
  thread and drives the agent with a **scripted model stub**
  (`tests/support/adk_stub.ScriptedToolCallModel`). It does **NOT** need a running mock and does
  **NOT** need a `GOOGLE_API_KEY` / real model. This is the key distinction from the manual
  `python -m agents.address` driver above — call it out clearly so a reader does not think they
  need API credentials to run the tests.
- The round-trip test shrinks the mock hold to ~1s and asserts (a) the payload matches the
  `gov-id-clean` entry in `wiki/evals/address/expected.json` and (b) `WORKING` was observed
  before `COMPLETED` (async poll path exercised).

**Lint (nice to include):** `uv run ruff check` (config in `pyproject.toml`).
