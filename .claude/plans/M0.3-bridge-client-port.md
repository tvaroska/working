# M0.3 — `BridgeClient` port (transport-agnostic seam + `a2a-sdk` adapter)

**Milestone:** 0 — Contract Tracer Bullet · **Task line:** `PLAN.md` M0.3
**Full milestone spec:** `docs/milestone-0-contract-tracer.md` (task 3) · **Stack ADR:** `docs/decisions/adr-0001-stack.md` · **Edge spec:** `wiki/bridge-a2a-edge.md`
**Depends on:** M0.2 (done — `contract` models exist and are importable). **Feeds:** M0.4 (mock server must speak the *exact* wire encoding this adapter reads/writes), M0.5 (agent wires this port as a tool), M0.6 (round-trip test drives this adapter and asserts the async path).

## Goal (scope of THIS task only)

Define the **transport-agnostic port** the agent core talks through — `BridgeClient.collect(request: CollectRequest) -> ExchangeTurn` — and provide **one adapter**, `A2ABridgeClient`, that implements it over the canonical A2A surface with `a2a-sdk`: `message/send` (return-immediately) → poll `tasks/get` until the task is terminal → decode the returned `ExchangeTurn`.

The port is the seam that makes the Sprint-1 **mock→real swap a no-op for the agent** (`docs/milestone-0-contract-tracer.md`). The agent only ever sees `collect(...) -> ExchangeTurn`; whether an A2A mock or the real Bridge answers is an adapter choice.

**Explicitly NOT in this task** (later M0 / Sprint 1):
- No mock server — that is M0.4. This task ships the *client* only. Its non-network logic (wire encode/decode) is unit-tested here; the live end-to-end round-trip is M0.6.
- No ADK agent / tool wiring — that is M0.5.
- No streaming (`message/stream`), no `tasks/resubscribe`, no push notifications, no cancel — polling (`tasks/get`) is the M0 async surface (`wiki/bridge-a2a-edge.md`; push webhooks are Phase 4).
- No second (GCP) adapter. See "Seams touched" — the local↔GCP split does not apply to *this* seam in M0.

## Critical context an executor MUST NOT re-derive

### The installed `a2a-sdk` is **1.1.2 — fully protobuf-typed**. The design docs predate it.
This is the single biggest gotcha. `docs/` and `CLAUDE.md` describe A2A in terms of the old pydantic 0.x types (`Message`/`Task`/`DataPart` as pydantic models, `message/send` returning a pydantic `Task`). **That API no longer exists in 1.1.2.** Verified facts about the installed version (`agents/.venv/.../a2a/`):

- **Types are protobuf messages**, generated in `a2a.types.a2a_pb2` and re-exported from `a2a.types`. Import them as `from a2a.types import Message, Part, Task, TaskState, Role, SendMessageRequest, GetTaskRequest`. They are **not** pydantic — build them with proto kwargs, read fields with `msg.field` / `msg.HasField('field')`, never `.model_dump()`.
- **Canonical transport is still JSON-RPC.** `TransportProtocol.JSONRPC` (from `a2a.utils.constants`; also referenced by the factory) is the default binding when `ClientConfig.supported_protocol_bindings` is empty. This satisfies ADR-0001's "canonical A2A via JSON-RPC". Do **not** use gRPC/HTTP+JSON bindings.
- **Client is async and built via a factory over an Agent Card:**
  - `A2ACardResolver(httpx_client, base_url).get_agent_card()` → `AgentCard` (fetches `/.well-known/agent-card.json`).
  - `ClientFactory(ClientConfig(...)).create(card)` → a `Client` (concretely `BaseClient`). All from `a2a.client`.
  - `ClientConfig` fields that matter: `httpx_client` (**required** for the JSONRPC transport — pass an `httpx.AsyncClient`), `streaming: bool`, `polling: bool`. Set **`streaming=False, polling=True`**. Rationale (verified in `base_client.py`): `streaming=False` forces the non-streaming code path (yields exactly one `StreamResponse`); `polling=True` sets `configuration.return_immediately`, so `message/send` returns the freshly-created task immediately instead of blocking for ~10s — which is exactly the long-running poll surface M0 must exercise.
- **`send_message` is an async *generator*.** `Client.send_message(SendMessageRequest, *, context=None) -> AsyncIterator[StreamResponse]`. In the `streaming=False` path it yields a single `StreamResponse`. Consume it with `async for resp in client.send_message(req): ...` (or `await anext(aiter(...))`). `StreamResponse` is a oneof: check `resp.HasField('task')` then read `resp.task` (a `Task`). (`resp.message` is the non-task reply shape — not expected here; treat as an error for M0.)
- **`get_task` returns a `Task` directly (not a stream):** `await client.get_task(GetTaskRequest(id=<task_id>)) -> Task`. `GetTaskRequest` field is **`id`** (a plain task-id string; there is no `name`/`tasks/{id}` resource wrapper in this version).
- **`Task` shape:** `task.id: str`, `task.context_id: str`, `task.status: TaskStatus`, `task.artifacts: list[Artifact]`. `task.status.state: TaskState`.
- **`TaskState` values** (proto enum ints, import the symbols): `TASK_STATE_SUBMITTED`, `TASK_STATE_WORKING`, `TASK_STATE_COMPLETED`, `TASK_STATE_FAILED`, `TASK_STATE_CANCELED`, `TASK_STATE_INPUT_REQUIRED`, `TASK_STATE_REJECTED`, `TASK_STATE_AUTH_REQUIRED`, `TASK_STATE_UNSPECIFIED`. Compare with `task.status.state == TaskState.TASK_STATE_COMPLETED`.
- **DataPart round-trip helpers** live in `a2a.helpers.proto_helpers`:
  - Build outbound message: `new_data_message(data, media_type="application/json", context_id=..., task_id=..., role=Role.ROLE_USER) -> Message`. `data` must be a **JSON-safe** dict (it is `ParseDict`-ed into a `google.protobuf.Value`). Passing `context_id=None` is safe (proto treats it as unset).
  - Read inbound structured payloads: `get_data_parts(parts) -> list[Any]` — each element is a plain dict (via `MessageToDict`). Use it on `artifact.parts`.

### The wire-encoding contract (DECISION — M0.4 MUST match this exactly)
`wiki/bridge-a2a-edge.md` and the M0 diagram: the Bridge returns an `ExchangeTurn` carrying a `CollectionStatus` **inside the completed task's artifact**. Because M0.3 (client) and M0.4 (server) must agree bit-for-bit and only M0.3 is being built now, **this plan fixes the encoding**; M0.4 must conform:

- **Outbound (client → Bridge):** the `CollectRequest` is a single JSON **DataPart** in one A2A `Message`, `media_type="application/json"`, `role=ROLE_USER`, `context_id = request.context_id or None`. Serialize with `request.model_dump(mode="json")` (**`mode="json"`** so the `context_id` optional and any future enums become JSON-native).
- **Inbound (Bridge → client):** on `TASK_STATE_COMPLETED`, the full **`ExchangeTurn`** (not a bare `CollectionStatus`) is a single JSON DataPart inside **`task.artifacts[0]`**. The client decodes `ExchangeTurn.model_validate(get_data_parts(task.artifacts[0].parts)[0])`. If the decoded `context_id` is empty/missing, backfill it from `task.context_id` (A2A's authoritative context id). Putting the whole `ExchangeTurn` in the artifact keeps the domain payload self-contained and transport-agnostic.
- Record a one-line note in the M0.4 plan/PR that it must emit this exact shape.

### Package placement & import discipline (honor the repo's seam idiom)
- Create a **new top-level src package** `agents/src/bridge_client/`, parallel to `agents/src/contract/`. It is the transport-agnostic port and must be independent of any specific agent — do **not** nest it under `agents/src/agents/`. This mirrors the repo rule that the client seam is agent-agnostic (analogue of `bridge/` never importing `agents/`).
- `bridge_client` imports **only** `contract` + stdlib + `a2a-sdk` + `httpx`. It must **not** import anything under `agents.*`. `contract` stays dependency-free (do not make `contract` import `bridge_client`).
- **Update `pyproject.toml`:** add `"src/bridge_client"` to `[tool.hatch.build.targets.wheel] packages` (currently `["src/agents", "src/contract"]`). Without this the package won't be installed in the wheel/editable env and imports will fail under `uv run`.

### Seams touched
This is the **`BridgeClient` seam** — the agent's port to the Bridge. In the repo's local/GCP framing this seam's "adapters" are *transport/target* choices (A2A-to-mock now; A2A-to-real-Bridge in Sprint 1), **not** an InMemory-vs-GCS backend pair. So M0 ships exactly one adapter (`A2ABridgeClient`) behind the abstract port; there is **no GCP adapter to write here** and none is implied. Keep the port abstract so Sprint 1 can add the real-Bridge target without touching agent code.

## Files to create / modify (ordered)

1. **`agents/pyproject.toml`** (modify) — add `"src/bridge_client"` to the wheel `packages` list.

2. **`agents/src/bridge_client/__init__.py`** (create) — module docstring + re-export the public surface:
   `from .port import BridgeClient, BridgeClientError` and `from .a2a_client import A2ABridgeClient`, with `__all__`.

3. **`agents/src/bridge_client/port.py`** (create) — the abstract port + error type:
   - `class BridgeClientError(Exception)` — base for adapter failures (timeout, terminal-non-completed, malformed payload). (A `BridgeTimeoutError(BridgeClientError)` subclass is nice-to-have for M0.6 assertions; optional.)
   - `class BridgeClient(abc.ABC)` with one abstract coroutine:
     `@abc.abstractmethod async def collect(self, request: CollectRequest) -> ExchangeTurn: ...`
     Use `abc.ABC` (a named, subclassable port), not a structural `Protocol` — adapters are explicit named subclasses, matching the "seam with adapters" idiom. Async because every real adapter is I/O-bound and ADK tools accept coroutines.

4. **`agents/src/bridge_client/a2a_client.py`** (create) — the `a2a-sdk` adapter. Structure it so the network-free logic is unit-testable:
   - **Module-level pure helpers** (no I/O — these are what M0.3's tests hit, and M0.4 mirrors on the server):
     - `def request_to_message(request: CollectRequest) -> Message` — `new_data_message(request.model_dump(mode="json"), media_type="application/json", context_id=request.context_id or None, role=Role.ROLE_USER)`.
     - `def task_to_exchange_turn(task: Task) -> ExchangeTurn` — guard `task.artifacts` non-empty and it has a data part; `datas = get_data_parts(task.artifacts[0].parts)`; raise `BridgeClientError` if empty; `turn = ExchangeTurn.model_validate(datas[0])`; if `not turn.context_id: turn = turn.model_copy(update={"context_id": task.context_id})`; return `turn`.
   - **`class A2ABridgeClient(BridgeClient)`**:
     - `__init__(self, base_url: str, *, httpx_client: httpx.AsyncClient | None = None, poll_interval: float = 0.5, poll_timeout: float = 30.0)`.
       Store config. If `httpx_client is None`, create one lazily and remember that we own it (so `aclose()` closes it; an injected client is the caller's to close). `poll_interval`/`poll_timeout` are **configurable specifically so M0.6 can shrink the mock's ~10s hold and keep the poll loop tight** — call this out.
     - Expose `self.observed_states: list[TaskState]` (reset at the start of each `collect`). Append the send-result state and each polled state. **This is an adapter impl detail, deliberately not on the `BridgeClient` port**, and exists so M0.6 can assert `TASK_STATE_WORKING` was observed before `TASK_STATE_COMPLETED` (proof the async poll path ran, not a blocking sleep). Document it as such.
     - `async def collect(self, request)`:
       1. Resolve card: `card = await A2ACardResolver(self._httpx, self._base_url).get_agent_card()`.
       2. Build client: `factory = ClientFactory(ClientConfig(httpx_client=self._httpx, streaming=False, polling=True))`; `client = factory.create(card)`. (Empty `supported_protocol_bindings` ⇒ JSONRPC.)
       3. Send: `msg = request_to_message(request)`; consume the one-shot generator — `async for resp in client.send_message(SendMessageRequest(message=msg)): task = resp.task; break` after asserting `resp.HasField('task')` (else raise `BridgeClientError`). Record `task.status.state`.
       4. Poll loop with a monotonic deadline (`loop = asyncio.get_running_loop(); deadline = loop.time() + self._poll_timeout`):
          - If `task.status.state == TASK_STATE_COMPLETED`: break.
          - If state in the terminal-failure set `{FAILED, CANCELED, REJECTED}` (and, for M0, treat `INPUT_REQUIRED`/`AUTH_REQUIRED` the same — no multi-turn in M0): raise `BridgeClientError` naming the state.
          - If `loop.time() >= deadline`: raise `BridgeClientError` (timeout) — or `BridgeTimeoutError` if added.
          - `await asyncio.sleep(self._poll_interval)`; `task = await client.get_task(GetTaskRequest(id=task.id))`; record state; repeat.
       5. Return `task_to_exchange_turn(task)`.
       Wrap the card-resolve/create/send in try/except and re-raise A2A/httpx errors as `BridgeClientError` (keep the original as `__cause__`) so agents see one stable exception type from the port.
     - `async def aclose(self)` — close the httpx client if owned. Also implement `__aenter__/__aexit__` for `async with A2ABridgeClient(...) as c:` ergonomics.

5. **`agents/tests/test_bridge_client.py`** (create) — network-free unit tests (a live server is M0.6):
   - `test_request_to_message_roundtrip`: build a `CollectRequest(party="jordan-lee", skill="address-proof")`, run `request_to_message`, then `get_data_parts(msg.parts)[0] == request.model_dump(mode="json")`; assert `msg.role == Role.ROLE_USER`.
   - `test_request_to_message_carries_context_id`: with `context_id="ctx-1"`, assert `msg.context_id == "ctx-1"`; and with `context_id=None` it builds without error (empty context id).
   - `test_task_to_exchange_turn_decodes_artifact`: construct a `Task` proto whose `artifacts[0]` has a data part built via `new_data_part(ExchangeTurn(...).model_dump(mode="json"))` (reuse the M0.2 `gov-id-clean` shape from `tests/test_contract.py`); assert the decoded `ExchangeTurn` equals the original.
   - `test_task_to_exchange_turn_backfills_context_id`: artifact `ExchangeTurn` has empty `context_id` but `task.context_id="ctx-9"` ⇒ decoded turn's `context_id == "ctx-9"`.
   - `test_task_to_exchange_turn_raises_on_missing_data_part`: a `Task` with no artifacts (or a text-only part) ⇒ `BridgeClientError`.
   - `test_port_is_abstract`: `BridgeClient` cannot be instantiated; `A2ABridgeClient` is a subclass (`issubclass(A2ABridgeClient, BridgeClient)`).
   - (Optional) `test_collect_times_out`: point `A2ABridgeClient` at an unroutable URL with `poll_timeout≈0.1` and assert `collect` raises `BridgeClientError` — only if it stays fast/offline; skip if it risks a real network wait.

## Gotchas checklist (do not trip on these)

- Do NOT treat A2A types as pydantic; they are protobuf (`a2a_pb2`). No `.model_dump()` on `Message`/`Task`.
- `send_message` is an async generator even in non-streaming mode — you must iterate it.
- Must pass an `httpx.AsyncClient` in `ClientConfig` or the JSONRPC transport can't be built.
- `request.model_dump(mode="json")` (not plain `model_dump()`) before handing to `new_data_message` — `ParseDict` needs JSON-native values.
- `GetTaskRequest(id=...)` uses `id`, not `name`.
- Use a monotonic clock (`loop.time()`) for the timeout, not wall-clock.
- Keep `collect` failures funneled to `BridgeClientError` so the agent (M0.5) has one exception type to handle.
